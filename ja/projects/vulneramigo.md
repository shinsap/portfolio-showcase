# Vulneramigo（ヴァルネラミーゴ）

## 概要

Vulneramigoは、PHP・Node.js・Oracle Javaの脆弱性情報を、Web制作会社とそのお客様の双方が理解できるレポートに整理する軽量なWebアプリ（PWA）です。セキュリティの専門家ではない方でも、更新が必要かどうか、次に何をすればよいかを把握できるよう、顧客とのコミュニケーションに役立つツールとして設計しています。

現在は公開済みで、https://vulneramigo.nortelia.co.jp/ で利用できます。

## 課題 → 解決

**課題：** サーバー側の技術に関する脆弱性情報は専門的な言葉で公開されています。Web制作会社はPHP・Node.js・Javaの更新がなぜ必要かをお客様に説明する場面が多く、中小企業のWebサイト担当者にとっては、その情報が自社に関係するのか、どの程度急ぐべきかを判断するのが難しい状況です。

**解決：** サイトで使っている技術を選び、バージョン情報を入力すると、ツールに収録済みの脆弱性情報（公式情報に基づくもの）と照合し、更新の必要性・推奨される対応・公式情報の参照先を分かりやすいレポートにまとめます。

照合の対象は、ツールに収録済みの情報と、利用者が入力したバージョンに限られます。Webサイトへのスキャン、脆弱性の自動発見、サイト全体の安全性診断は行いません。この範囲はレポート上にも明記しています。また、判断に必要な情報が足りない場合は「安全」と表示せず、判定できないことをそのまま伝えます。

**対象ユーザー：** お客様のWebサイトを保守しているWeb制作会社、中小企業のWebサイト担当者。

## 主な機能

- 日本語・英語・スペイン語の画面とレポート
- Webサイト担当者向けの平易なまとめ
- 同じレポート内に制作会社向けの技術情報
- 推奨される対応と公式情報へのリンク
- ブラウザからの印刷・PDF保存（お客様との打ち合わせ資料として共有可能）
- 入力情報はブラウザ内で処理し、サーバーへの送信や保存は行わない設計

## 状態

- **開発：** 公開済み / 継続運用
- **公開：** https://vulneramigo.nortelia.co.jp/

## 担当範囲

- プロダクト企画、顧客コミュニケーション支援ツールとしての位置づけ整理
- 要件定義（レポートが示すこと・示さないことの範囲と表現を含む）
- 担当者向け・制作会社向けの2種類の読み手を想定したレポートと画面フローの設計
- 多言語コンテンツ設計（日本語 / 英語 / スペイン語）
- ブラウザ完結型PWAの実装
- 公式情報に基づく収録データの整備

## 技術スタック

- React
- TypeScript
- Vite
- PWA（Service Worker）
- Cloudflare Workers（静的アセット配信）
- Vitest

## 伝えられること

- 専門的な技術情報を、顧客とのコミュニケーションに使える成果物へ落とし込む設計
- 非技術者の意思決定者と技術者という、2種類の読み手を同時に想定した設計
- ツールの対象範囲を明確にし、断定しすぎない表現の設計
- 入力情報をブラウザ内で処理するプライバシーに配慮した設計
- 国内外の利用者を想定した多言語プロダクト設計
