# Vulneramigo（ヴァルネラミーゴ）


## プレビュー配信での不具合と復旧確認

PR #2では、本番公開前のプレビュー環境でキャッシュ不具合を確認しています。`/version.json`へのアクセスによって`/`の画面キャッシュへJSONが混入する問題と、インストール失敗時に利用可能なキャッシュを損なう問題です。ブラウザで再現し、画面遷移時のキャッシュ書き込み条件と、同じキーでの再インストール失敗時に現行キャッシュを保持する処理を修正しました。

修正前コードで失敗する回帰テスト2件を追加し、当時の90テストが通過。Chromeでオフライン利用・更新・ロールバック・更新失敗時の旧版維持を確認しました。本番障害の実績ではなく、公開前の検証で問題を発見し、復旧挙動まで確認した事例です。

## 概要

Vulneramigoは、Webサイトのセキュリティ設定と、PHP・Node.js・Oracle Java SE・Next.jsの脆弱性情報を、Web制作会社とそのお客様の双方が理解できるレポートに整理する軽量なWebアプリ（PWA）です。セキュリティの専門家ではない方でも、何を改善すべきか、次に何をすればよいかを把握できるよう、顧客とのコミュニケーションに役立つツールとして設計しています。

現在は公開済みで、https://vulneramigo.nortelia.co.jp/ で利用できます（BETA）。

## 課題 → 解決

**課題：** セキュリティ設定やサーバー側の技術に関する脆弱性情報は専門的な言葉で公開されています。Web制作会社はPHP・Node.js・Java・Next.jsの更新がなぜ必要かをお客様に説明する場面が多く、中小企業のWebサイト担当者にとっては、その情報が自社に関係するのか、どの程度急ぐべきかを判断するのが難しい状況です。

**解決：** 単独でも、1つのレポートにまとめても使える2つの診断を提供します。

- **URL診断（BETA・非侵入型）：** 自分が管理している、または診断の許可を得ているサイトのURLを入力すると、外部から確認できる公開設定を調べます。対象は、HTTPSとHTTPからHTTPSへのリダイレクト、HTTPセキュリティヘッダー、メール・DNS関連の設定（SPF・DMARC・MX・CAA）です。結果は「確認できた項目」「改善を推奨する項目」「確認できなかった項目」に分け、平易な説明と改善のヒントを添えます。
- **バージョン照合：** PHP・Node.js・Oracle Java SE・Next.jsを選び、バージョンを入力すると、ツールに収録済みの脆弱性情報（公式情報に基づくもの。Next.jsはGHSA 26件）と照合し、関連する情報・更新の必要性・公式情報の参照先を表示します。

範囲は明記しています。URL診断は外部から見える公開設定の簡易な確認で、サイトの内部をスキャンするものではなく、URLからPHP・Node.js・Java・Next.jsのバージョンを特定するものでもありません。サイト全体の安全性を保証するものでもありません。バージョン照合は、収録済みの情報と入力されたバージョンに限られ、すべての脆弱性を網羅するものではありません。判断に必要な情報が足りない場合や公式情報に食い違いがある場合は、「安全」と表示せず、判定できないことをそのまま伝えます。

**対象ユーザー：** お客様のWebサイトを保守しているWeb制作会社、中小企業のWebサイト担当者。

## 主な機能

- PHP・Node.js・Oracle Java SE・Next.jsの4製品について、公式情報に基づく収録済みの脆弱性情報とバージョンを照合
- URL診断（BETA）：HTTPS・セキュリティヘッダー・DNS・SPF／DMARCなどのメール関連設定を、確認できた／改善推奨／確認不能に分けて表示
- Webサイト担当者向けの平易なまとめと、制作会社向けの技術詳細・公式情報へのリンク・確認事項を同じレポートに掲載
- ブラウザからの印刷・PDF保存（URL診断の結果もレポートに掲載）
- 任意のPDF付録「アクセスしたあなたの環境から分かること」：Webサイトを訪れたときにブラウザや端末から分かる情報を示す。利用者が選んだ場合のみブラウザ内で取得し、サーバーへの送信や保存、追跡用IDの生成は行わない
- Oracle CVE-2026-114820の公式Security Alertへ案内する追加の注意喚起。診断結果とは別のもので、個別の環境が影響を受けるかどうかを判定するものではない
- 日本語・英語・スペイン語の画面とレポート
- URL診断の注意書きの下に、任意の「開発者を支援する」リンク

## データの扱い

- **バージョン照合：** 主にブラウザ内で実行します。入力したバージョンはブラウザ内で処理されます。
- **URL診断：** 入力したURLは、アプリの診断用サーバー（Cloudflare Worker）へ送信されます。診断用サーバーは、対象サイトとDNSの公開情報を確認します。URL診断の結果はアプリ側では保存しません。Cloudflareのアクセスログやレート制限の情報は残る可能性があります。
- 入力するのは、自分が管理している、または診断の許可を得ているサイトに限ります。

## 担当範囲

- プロダクト企画、顧客コミュニケーション支援ツールとしての位置づけ整理
- 要件定義（レポートが示すこと・示さないことの範囲と表現を含む）
- 担当者向け・制作会社向けの2種類の読み手を想定したレポートと画面フローの設計
- 多言語コンテンツ設計（日本語 / 英語 / スペイン語）
- 非侵入型URL診断の設計・実装（確認できた／改善推奨／確認不能の整理）
- ブラウザ上で動くPWAの実装
- 公式情報に基づく収録データの整備

## 技術スタック

- React
- TypeScript
- Vite
- PWA（Service Worker）
- Cloudflare Workers（静的アセット配信、URL診断用サーバー）
- Vitest

## 伝えられること

- 専門的な技術情報を、顧客とのコミュニケーションに使える成果物へ落とし込む設計
- 非技術者の意思決定者と技術者という、2種類の読み手を同時に想定した設計
- ツールの対象範囲を明確にし、断定しすぎない表現の設計
- ブラウザ内で処理する部分とサーバーへ送信する部分を区別した、プライバシーに配慮した設計
- 観測できたこと・推定・取得できないことを分け、何が言えて何が言えないかを明確にする設計
- 国内外の利用者を想定した多言語プロダクト設計
