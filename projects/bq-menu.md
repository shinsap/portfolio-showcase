# BQmenu

## Overview

BQmenu is a digital menu and information system designed for hotel banquet operations. It helps reduce repeated work around printed menus, venue guidance, and QR-based guest access while keeping the staff workflow simple and difficult to misuse.

The MVP is complete, with a production environment and an on-device demo using actual PCs and smartphones. It is presented as a private demo, not as an adopted customer deployment.

## What I Built

- A staff-facing banquet management interface
- Registration of event information and PDF menus
- Smartphone menu access via QR codes
- Time-based content availability
- Data separation designed for multiple properties
- UX refinement for both staff-facing and guest-facing screens
- Automated tests, real-browser verification, and an operation manual

## Outcome

Completed the MVP and conducted an on-device demo on actual PCs and smartphones. The interface was refined around the principle that staff should be able to operate it quickly, with minimal hesitation or mistakes.

## Role

Handled the project end-to-end: concept definition, requirements, UI/UX, implementation, testing, production setup, and documentation. AI coding tools were incorporated into the workflow, with repeated review and testing used to maintain quality.
