# Hokkaidoku

## Overview

Hokkaidoku is a Hokkaido-themed logic puzzle PWA where players help Ezo deer find their territories. Players place one deer in each colored region, row, and column, without letting any deer touch.

Public URL: https://hokkaidoku.nortelia.co.jp/

Status: Test version / public

The source repository is private.

## Key Features

- Daily puzzle and free play
- Generated boards from 6×6 to 12×12, each with one solution and no guessing required
- Collectible Hokkaido facts (50) and illustrated scenes (10)
- Hints that explain their reasoning
- Japanese and English support
- Works offline and requires no installation
- Local save data with a transfer code

## Development Process

Product planning, game design, and acceptance decisions were led by Shinya. Claude Code handled implementation, and Codex handled code review.

## Stack

- TypeScript
- Vite
- Web Worker
- PWA
- Cloudflare Workers
- PostHog
